Exercício feito com o intuito de demonstração de meios para tratar dados. Contendo 3 tipos de resoluções: muito ruim (uma solução funcional, porém englobando diversos if-elses [Arrow Anti-Pattern]),
ruim (organizando e redistribuindo para melhor legibilidade do código)
e bom (utilizando de try-catch e também exceções personalizadas [no caso, o DomainException]).
